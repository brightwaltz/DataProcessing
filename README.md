## 使い方

- スマホでも PC でも開けます。動画は「再生」を押すと始まり、途中で予想を聞かれます。
- 解いた結果やメモは、使っているブラウザの中（localStorage）だけに保存されます。外部へは送られません。予習・復習ページの提出は不要です（オンデマンド教材の提出は WebClass）。
- 練習問題は練習用に作ったもので、課題の答えそのものではありません。授業の資料と課題は WebClass にあります。
